# 칩이 (Chip-i) · 삼성전자 DS 반도체 챗봇

작은 실리콘 칩 캐릭터가 반도체 이야기를 도와주는 로컬 웹 챗봇입니다.
삼성블루(`#1428A0`) 테마 · 웨이퍼/회로 패턴 배경 · DRAM 셀 모양 메모리 게이지.

- 💬 반도체 전문 대화 (최근 10턴 기억)
- 📄 PDF를 올리면 **그 문서 내용만으로** 답변 (출처 페이지 표기)
- 📮 최근 10턴을 요약해 메일로 발송

## 실행

```bat
run.bat
```

또는

```bash
python app.py
```

브라우저가 자동으로 `http://127.0.0.1:8000` 을 엽니다. (8000 사용 중이면 8001…로 자동 증가)

> **별도 설치 필요 없음** — Python 표준 라이브러리만 사용합니다. (Python 3.9+)

## 설정

모든 설정은 `app.py` 상단에 모여 있습니다.

| 항목 | 값 | 변수 |
|---|---|---|
| 모델 | `gpt-5.4-mini` | `MODEL` |
| 한 턴 최대 출력 토큰 | `1000` | `MAX_COMPLETION_TOKENS` |
| 대화 기억 | 최근 `10`턴 | `MEMORY_TURNS` |
| 추론 강도 | `none` | `REASONING_EFFORT` |
| 성격/말투 | 칩이 페르소나 | `SYSTEM_PROMPT` |

`REASONING_EFFORT`는 `none / low / medium / high / xhigh` 중 선택할 수 있습니다.
추론 토큰도 1000토큰 한도를 함께 쓰므로, 높이면 실제 답변 길이가 줄어듭니다.

## API 키

프로젝트 루트의 `.env` 파일에서 읽습니다.

```
OPENAI_API_KEY=sk-...
```

`.env`는 `.gitignore`에 등록돼 있어 커밋되지 않습니다.
새로 세팅할 때는 `.env.example`을 복사해 쓰세요.

## 구조

```
삼성DS챗봇/
├── app.py             # HTTP 서버 + OpenAI 호출 + 10턴 메모리 + 라우팅
├── pdfdoc.py          # PDF 추출 · 청킹 · 질의 검색(BM25)
├── mailsend.py        # 대화 요약 메일 (본문 렌더링 + 발송 위임)
├── index.html         # 칩이 UI (삼성블루 테마, 단일 파일)
├── .env               # API 키 (커밋 안 됨)
├── .env.example       # 키 템플릿
├── mail_settings.json # 고정 수신인 (커밋 안 됨, 자동 생성)
└── run.bat            # 더블클릭 실행
```

## 문서 기반 답변 (PDF)

우측 **문서 캐비닛**에 PDF를 올리면(클릭 또는 드래그앤드롭) 챗봇이
**문서 기반 답변 모드**로 바뀝니다.

- 텍스트 추출은 PyMuPDF → pypdf → pdfplumber 순으로 시도합니다.
- 페이지 번호가 붙은 청크로 자른 뒤, 질문과 관련 높은 청크만 골라
  모델에 넣습니다 (BM25 유사 스코어링, 한글은 2-gram).
- 이 모드에서는 **업로드한 문서 내용만** 근거로 답합니다.
  문서에 없으면 지어내지 않고 "찾지 못했어요"라고 답하며,
  외부 지식이나 검색은 쓰지 않습니다. (`temperature` 0.2)
- 답변 아래에 `📄 파일명 p.N` 출처 배지가 붙습니다.
- 문서를 모두 빼면 다시 일반 대화 모드로 돌아갑니다.

한도: PDF만 · 파일당 20MB · 한 턴에 넣는 발췌 24,000자
(`MAX_UPLOAD_MB`, `MAX_CONTEXT_CHARS`).
스캔 이미지로만 된 PDF는 글자가 없어 읽지 못합니다 (OCR 미지원).

## 대화 요약 메일

우측 패널 상단에서 **최근 10턴을 정리해 메일로** 보낼 수 있습니다.

- 발송은 옆 프로젝트의 공용 모듈을 그대로 씁니다:
  `C:\AI\삼성DS이메일자동화\mailer.py` (네이버 SMTP)
- 계정 정보와 주소록도 그쪽 파일을 따릅니다
  (`네이버SMTP계정정보.txt`, `수신인정보.txt`).
  주소록에 등록된 이름은 패널에 칩으로 떠서 클릭하면 입력됩니다.
- 📌 버튼으로 **고정 수신인**을 저장하면 다음부터 자동으로 채워집니다
  (`mail_settings.json`).
- 대화를 JSON 스키마로 요약해 삼성블루 HTML 메일로 만듭니다 —
  한눈에 보기 / 주요 문답 / 키워드 / 확인 필요 항목 + 전체 대화 기록.
  요약에는 대화에 실제로 나온 내용만 씁니다.
- 요약 호출은 채팅과 별개로 `MAIL_SUMMARY_MAX_TOKENS`(2000)를 씁니다.
  채팅 한 턴은 그대로 1000토큰입니다.

### 메모리 동작

대화는 서버 메모리에 세션 단위(`sid`)로 보관되며, 매 턴마다
`user`/`assistant` 쌍 기준 **최근 10턴**만 남기고 잘라냅니다.
`SYSTEM_PROMPT`는 항상 맨 앞에 유지됩니다.

`sid`는 브라우저 `localStorage`에 저장돼서 새로고침해도 대화가 이어지고,
헤더의 **기억 초기화** 버튼을 누르면 서버 쪽 기록까지 비웁니다.
서버를 재시작하면 모든 대화는 사라집니다.

## 참고

- GPT-5 계열은 `max_tokens`가 아니라 `max_completion_tokens`를 씁니다.
- 서버는 `127.0.0.1`에만 바인딩되어 외부에서 접근할 수 없고,
  API 키는 브라우저로 내려가지 않습니다.
